# فونت Peyda

این پوشه باید شامل فایل‌های woff2 فونت **Peyda** با وزن‌های زیر باشد:

| فایل | وزن | نام |
|---|---|---|
| `Peyda-Regular.woff2` | 400 | Regular |
| `Peyda-Medium.woff2` | 500 | Medium |
| `Peyda-SemiBold.woff2` | 600 | SemiBold |
| `Peyda-Bold.woff2` | 700 | Bold |

## راهنمای دانلود

1. به مخزن رسمی فونت Peyda بروید:
   `https://github.com/rastikerdar/peyda-font` (یا منبع رسمی دیگر)
2. فایل‌های woff2 با نام‌های بالا را در همین پوشه کپی کنید.
3. **لایسنس open-source فونت را حتماً چک کنید** (طبق بخش ۱۱ سند).

## وایرینگ

وایرینگ در `app/fonts.ts` انجام شده و آماده است؛ به‌محض قرار گرفتن فایل‌ها، فونت به‌صورت خودکار لود می‌شود. متغیر CSS: `--font-peyda`.

> اگر فایل‌ها موجود نباشند، build با خطا مواجه می‌شود. برای تست بدون فونت، مسیرهای `src` در `app/fonts.ts` را موقتاً حذف کنید یا فایل‌های جایگزین با همان نام‌ها بگذارید.
